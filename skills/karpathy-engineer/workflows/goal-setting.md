# Workflow: Goal Setting

<required_reading>
None — this workflow depends on the `grill-me` skill, not on create-agent-skills reference files.
</required_reading>

<process>
If the real goal is unknown, use `grill-me` to interview and find the **real goal** of the project + the core decision (if any) the project intends to drive.
</process>

<success_criteria>
This workflow is complete when:
- [ ] The real goal is explicit and agreed, not assumed.
- [ ] Any core decision the project intends to drive is named.
- [ ] Ready to move to `project-planning.md`.
</success_criteria>
