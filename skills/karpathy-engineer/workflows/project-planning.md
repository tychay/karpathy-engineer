# Workflow: Project Planning

<required_reading>
None — this workflow depends on the `grill-me` skill, not on create-agent-skills reference files.
</required_reading>

<process>
Break the project into small, agile buckets. Build one bucket at a time — this ordered set of buckets is what `agile-loop.md` iterates over.

If re-entered from `agile-loop.md`'s Adjust step: check whether the plan needs adjustment given the last checkpoint's review. If so, or unsure, use a `grill-me` retrospective to determine the adjustment.
</process>

<success_criteria>
This workflow is complete when:
- [ ] The project is decomposed into an ordered list of small, agile buckets.
- [ ] The next (or first) bucket is identified.
- [ ] Ready to hand off to `agile-loop.md`.
</success_criteria>
